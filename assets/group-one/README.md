# Group One WebP atlases

Upload six generated binary assets here: `atlas-01.webp` through `atlas-06.webp`.

Each atlas is 1448×1086 (4×3 square tiles). Their deterministic mapping is recorded in `data/group-one-visual-assets.json`.

The lesson viewer continues to use old verified photos and explanatory cards until an atlas file is uploaded. Do not use a PNG or differently sized file here.
