# Learn English · Pattern Universe

An Arabic-first, offline-friendly learning prototype that teaches English **through scenes, patterns, contrasts, and active recall**.

## المجموعة الأولى — المسار التفاعلي
- [المجموعة الأولى: 18 نمطًا و72 موقفًا و54 سطر قصة و36 جملة حوارية](docs/GROUP-ONE-AR.md). افتح تبويب «🌱 المجموعة الأولى».
- اختبار الفهم وبناء الجملة وحفظ التقدم، وأولوية للأصول الصوتية الموثقة.
- يوضح [تقرير الحالة](docs/GROUP-ONE-AR.md) ما يحتاج استكمالًا من الصور والتسجيلات قبل اعتماد الوسائط.

## المجموعة الرابعة — الأسئلة والاستفسارات
- [المجموعة الرابعة: 18 نمطًا و72 موقفًا وثلاث قصص مترابطة](docs/GROUP-FOUR-AR.md). افتح «❓ المجموعة الرابعة».
- قارن بين **What / Where / When / Why / How** وبين **Do / Does** و**Is there / Are there** و**How many / How much**، مع التدريب والتسجيلات المزامنة بالكلمات؛ 197 تسجيلًا خاصًا وصوت واحد مطابق مُعاد الاستخدام من المكتبة الأساسية.
- الصور الواقعية مؤجلة؛ تظهر بدائل توضيحية حتى تصميم أطالس WebP الفعلية.

## المجموعة الخامسة — الماضي والذكريات وسرد الأحداث
- [المجموعة الخامسة: 18 نمطًا و72 موقفًا وثلاث قصص مترابطة](docs/GROUP-FIVE-AR.md). افتح «🕰️ المجموعة الخامسة».
- أنماط الماضي البسيط والنفي والسؤال والأفعال الشاذة والماضي المستمر و`used to`، مع ترجمة ومقارنات واختبارات وتركيب جمل وحفظ تقدم منفصل. الصور الفوتوغرافية مؤجلة.
- **اكتمل الصوت: 198/198 مقطعًا موثقًا** (197 تسجيل MP3 جديدًا + مقطع واحد مطابق من المكتبة السابقة)، مع توقيت الكلمات من التسجيل الحقيقي، والرجوع لنطق المتصفح عند تعذر تحميل ملف.

## المجموعة السادسة — المستقبل والخطط والاحتمال
- [المجموعة السادسة: 18 نمطًا و72 موقفًا وثلاث قصص مترابطة](docs/GROUP-SIX-AR.md). افتح «🗓️ المجموعة السادسة».
- **I'll / won't / Will you**، **going to** للنوايا، **I'm meeting** للترتيبات، **The class starts** للجداول، **hope / expect / might / may / probably** لدرجات التوقع، **about to** للفورية، **if / when / as soon as** للشرط والزمن المستقبلي.
- **198/198 تسجيل MP3 إنجليزي مكتمل ومتحقق منه** مع بيانات توقيت الكلمات المقاسة من الصوت نفسه وبصمات SHA256. الصور الواقعية مؤجلة عمدًا، وتظهر بدائل توضيحية خفيفة.

## المجموعة السابعة — المشاعر والآراء والانطباعات

## المجموعة التاسعة — ربط الأفكار وتوسيع التعبير
- [المجموعة التاسعة: 18 نمطًا و72 موقفًا وثلاث قصص مترابطة](docs/GROUP-NINE-AR.md). افتح «🔗 المجموعة التاسعة».

## مراجعة المجموعات العشر على main
- يحتوي المسار التعليمي التفاعلي على **10 مجموعات × 18 نمطًا = 180 نمطًا معمقًا**، و**10 × 72 = 720 موقفًا**، إضافة إلى الدروس المعمقة الثلاثة ومسرد المصدر الذي يضم **1,034 مدخلًا**. ليست المدخلات الأصلية الـ1,034 كلها دروسًا معمقة بعد.
- تحقق مستقل: `python scripts/audit_ten_groups.py` يفحص ملفات `data/group-{name}.json` وعرضها وتكاملها في `index.html` و`app.js` و`server.mjs`.
- فحص الجوال الحقيقي في `scripts/smoke_group_ten.mjs` يفتح **المجموعات العشر كلها** ويختبر تفاعل المجموعة العاشرة؛ الصور لا تدخل في اعتماد هذه المرحلة.

## Learning experience
- Three fully scripted seed lessons from the supplied source: **This is my house**, **I have a good job**, and **I've got a job**.
- Each seed lesson includes three levels, 12 contextual scene examples, a recorded Kokoro explanation, clickable story chapters (5 lines per level), a 4-turn dialogue, active vocabulary highlighting and quiz/reconstruction.
- Browse and search all source entries with keyword categories, depth filters and relationship links. Automatic labels are provisional until linguistic review.
- English audio: 15 verified Kokoro-82M MP3 files committed (3 explanations + 12 beginner scenes); GitHub Actions now generates 45 narrated story lines and 12 dialogue clips as additional MP3 assets. Browser TTS is the fallback for pending or missing recordings. Audio generation needs a successful workflow before a new file can be considered present.
- GitHub Actions site preview artifact, and GitHub Pages deployment when Pages is enabled for this repository/account.

## Stories and synchronisation
- `data/stories.json` contains **3 original stories**, **9 chapters**, **45 story lines** and **12 dialogue turns** with Arabic translations and contextual illustrations.
- While using browser speech synthesis, word highlighting uses speech engine boundary events when supported.
- For MP3 recordings, the interim time-based word highlight is **approximate**, not verified forced alignment. Production-grade forced alignment is still to be implemented. See `docs/STORY-AUDIO.md`.

## Run
Open `index.html` with a local static server or browse the GitHub Pages site after its first successful deployment. No backend, credentials or payment necessary.
