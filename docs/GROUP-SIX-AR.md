# المجموعة السادسة — المستقبل والخطط والنية

## المحتوى المنفذ
تتابع هذه المجموعة الماضي في المجموعة الخامسة وتعلم صياغة حديث طبيعي عن الأحداث القادمة، وليس مجرد حفظ will.

- **18 نمطًا**، لكل نمط شرح بالعربية والإنجليزية وصيغة ومقارنة وارتباط بالمصدر الأصلي.
- **72 موقفًا مترجمًا**، **54 سطر قصة**، **36 دور حوار**، و**18 سطرًا** في ثلاث قصص متصلة:
  1. **The Weekend Plan** — خطة عطلة الأسبوع.
  2. **The School Project** — مشروع المدرسة.
  3. **The Journey Home** — رحلة العودة.
- **198 مادة صوتية مستهدفة**: شرح + أربعة مواقف + ثلاثة سطور قصة + دوران للحوار لكل نمط، بالإضافة إلى 18 سطرًا في الفصول الثلاثة.
- **الصور الفوتوغرافية مؤجلة عمدًا**: بطاقات خفيفة متجاوبة بدلًا من الصور أو أطالس WebP غير المنتجة.

## المقارنات التي يجب إتقانها
- **I'll help** قرار لحظي أو وعد؛ **I'm going to help** نية سابقة؛ **I'm meeting Ali tomorrow** موعد مرتب.
- **The bus leaves at seven** جدول ثابت مستقبلًا يستخدم المضارع البسيط.
- **I'll probably go** ترجيح؛ **I might / may go** احتمال؛ **I hope to go** أمنية؛ **I expect to go** توقع.
- **I'm about to leave** حدث وشيك وليس خطة بعيدة.
- **If it rains, I'll stay home** شرط ممكن؛ **When I get home, I'll call** حدث متوقع؛ **As soon as I get home** تسلسل فوري. في الجمل الزمنية والشرطية المستقبلية نستعمل المضارع البسيط بعد **if/when/as soon as** عادةً وليس `will`.
- **sourceIds** تُحيل إلى أنماط مشابهة في المصدر الأصلي ذي 1,034 مدخلًا. التوسعات التعليمية والجمل الجديدة ليست اقتباسًا حرفيًا منه.

## تفاعل التعلم
- تسجيل MP3 مع توقيتات كلمات مقاسة من التسجيل عند توافرهما والتحقق من بصمته SHA256، وبديل واضح بنطق المتصفح عند غيابهما.
- استماع طبيعي وبطيء ومتتابع، وقصص وحوارات وترجمة عربية ومقارنات بين الأنماط.
- اختبار الفهم وإعادة تركيب العبارة، ولا تُحسب التجربة مكتملة إلا بعد نجاح كليهما. حفظ تقدم منفصل عن المجموعات السابقة.
- دعم الهاتف والتابلت دون تمرير أفقي.

## فحص القبول
```bash
npm run check
node --check group-six.js
python scripts/test_group_six.py
# بعد إصدار التسجيلات والتوقيتات:
python scripts/test_group_six.py --require-audio
node scripts/smoke_group_six.mjs
```

فهرس `data/group-six-audio-index.json` يبدأ دون ملفات مزعومة؛ تنشئ `.github/workflows/group-six-voices.yml` التسجيلات الفعلية وتُجري التحقق. لا يغني نجاح التحقق الآلي عن اختبار النطق البشري النهائي على الأجهزة.
