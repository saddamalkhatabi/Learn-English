# المجموعة الثالثة — القدرة والاحتياج والإذن والنصيحة والدعوة

## أسلوب التعلم

تستكمل هذه المجموعة تسلسل المجموعة الأولى (التعريف والرغبات) والثانية (الروتين والعادات) عبر مواقف تواصل فعلي: أستطيع، لا أستطيع، هل يمكنك؟ هل يمكنني؟ كيف أطلب الإذن؟ ما الذي أحتاج إليه؟ ما الذي يجب وما الذي يُنصح به؟ وكيف أقترح وأدعو بأدب؟

**المحتوى المكتوب:** 18 نمطًا مستقلًا مع شرح عربي وإنجليزي، صيغة ومقارنة مع الأنماط القريبة؛ 72 موقفًا تطبيقيا، 54 سطرًا قصصيًا، 36 جملة حوارية، إضافة إلى 3 قصص تربط الأنماط (18 سطرًا). هذا ينتج **198 مقطعًا صوتيًا مستهدفًا**: شرح + 4 مواقف + 3 قصة + 2 حوار لكل نمط، و18 سطرًا للقصص المتصلة.

**الفروق الجوهرية:** `I can / I can't`؛ `Can you / Can I / Is it okay if / You may`؛ `I need / I need to / I have to / I don't have to / I must`؛ `I should / You should`؛ `Let's / Let me`؛ `Please`؛ `Would you like / Would you like to`.

- **I don't have to** يعني غياب الإلزام وليس المنع، وهو يختلف تمامًا عن **mustn't**.
- **I need + noun** تختلف عن **I need to + verb**.
- **Would you like + noun?** تعرض شيئًا، أما **Would you like to + verb?** فتدعو إلى فعل.
- **Let's** تشمل المتحدث وغيره، أما **Let me** فيقوم فيها المتحدث بالفعل.
- **Can you** للقدرة أو لطلب المساعدة، أما **Can I** فغالبًا لطلب الإذن أو عرض المساعدة.
- بعض الأمثلة توسع تعليمي خُصص للسياق؛ `sourceIds` تحفظ الإحالة إلى أمثلة حقيقية من المصدر الأصلي 1034 مدخلًا، وليست ادعاء بأنها نمط أصلي مستقل في المصدر.

## الوسائط ومزامنة الكلمات

استُخدمت بطاقات مشاهد بسيطة واقعية المعنى كبديل مؤقت للصور؛ تصميم أطالس WebP للمجموعة الثالثة مؤجل عن قصد.

- يستخدم صوت إنجليزي مسجل مع بيانات WordBoundary من نفس عملية توليد MP3، وترتبط كل كلمة بوقت البداية والنهاية بدلًا من أي تقدير اعتباطي.
- يولِّد `scripts/render_group_three_audio.py` تسجيلات `assets/group-three-audio/` ويتحقق من SHA256 وأزمنة الكلمات.
- تُنشئ المعاينة العامة حزمًا صوتية تدريجية `assets/group-three-audio-bundles/` تحمل النص نفسه والتوقيتات وتُحمّل عند فتح النمط أو القصة.
- لا يُعدّ الصوت مكتملًا إلا بعد نجاح وظيفة GitHub Actions ووجود تسجيلات المجموعة. إذا غاب ملف يستخدم المتصفح TTS دون الادعاء بوجود توقيت كلمات مقاس.
- المراجعة السمعية البشرية على الأجهزة المختلفة ضرورية حتى بعد نجاح التحقق البرمجي.

## اختبارات القبول

```bash
npm run check
node --check group-three.js
python scripts/test_group_three.py
```

- افتح تبويب المجموعة الثالثة على الهاتف، وتأكّد من وجود 18 نمطًا و72 مشهدًا و3 قصص متصلة.
- جرّب التمارين، وترتيب الكلمات، والإجابة الصحيحة والخاطئة، والتقدم بعد إعادة تحميل الصفحة.
- استمع إلى الجمل والشرح والقصص، وتحقق من تلوين الكلمات في الأوقات المحددة لها وإيقاف التشغيل.
- تأكد من عدم تغيير المجموعة الأولى أو الثانية أو الدروس والمكتبة السابقة.
- الصور الواقعية ليست جزءًا من شروط قبول هذه المرحلة؛ اختبر جودة بديلها الحالي فقط.
