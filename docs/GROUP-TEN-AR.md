# المجموعة العاشرة — التعبير المركب وبناء الجمل المتقدمة

## الهدف
منح المتعلم قدرة على الجمع بين **توضيح المعنى وتحديد الأولويات**، و**الأسئلة غير المباشرة**، و**الجمل الموصولة**، و**الخيال والشرط المخالف للواقع**، و**مراجعة الماضي وترتيب أحداثه**، و**تغيّر متلازم في المقارنات**.

## تفاصيل الإنتاج
- 18 نمطًا مع صيغ وشرح بالعربية والإنجليزية ومقارنات دقيقة وإحالات مصدرية.
- 72 موقفًا مترجمًا (أربعة لكل نمط).
- 54 سطر قصة مصغرة، و36 دور حوار، و18 سطرًا داخل ثلاث قصص مرتبطة:
  - **A Thoughtful Classroom** — صف يفكر بعمق.
  - **The Missed Opportunity** — الفرصة التي فاتت.
  - **The Future Inventors** — مخترعو المستقبل.
- **اكتمل الصوت: 198/198 ملف MP3 جديدًا** للشروح والمواقف والقصص والحوارات، مع تلوين الكلمات وفق WordBoundary مستخرج من التسجيل نفسه والتحقق من SHA256 لكل ملف. لم تُستخدم تسجيلات سابقة، واجتاز الفهرس `data/group-ten-audio-index.json` فحص `--require-audio`.
- الصور الواقعية وأطالس WebP **مستثناة عمدًا** وتعرض بدائل رسومية خفيفة متجاوبة.

## مقارنات أساسية لا ينبغي خلطها
- **What I mean is** لتوضيح فكرة سبق قولها؛ **What matters is** لتحديد الأهم؛ **The reason is that** لتفسير سبب محدد.
- **I wonder if** للسؤال غير المباشر بنعم أو لا؛ **I wonder how** للسؤال عن الطريقة؛ **Could you tell me whether** لسؤال مهذب ذي ترتيب خبري داخل الجملة.
- **The person who** لوصف إنسان، و**The book that** لوصف شيء، و**The place where** لوصف مكان، و**The day when** لوصف وقت.
- **I wish I could** أمنية تتعلق بقدرة غير متاحة الآن؛ **If I were ..., I would ...** تخيل في الحاضر غير واقعي؛ **If I had ..., I would have ...** إعادة تصور ماضٍ لم يحدث.
- **I should have** حكم بأن فعلًا ماضيًا كان أفضل؛ **I could have** قدرة أو فرصة ماضية لم تتحقق بالضرورة.
- **I had already** يبين فعلًا ماضيًا اكتمل قبل حدث آخر؛ **By the time** يحدد نقطة مقارنة في تسلسل الأحداث الماضية.
- **The more ..., the more** يربط تغيرين متدرجين؛ التغيّر الثاني قد يأخذ صيغة **better** أو **less** بحسب المعنى.

## الصلة بالمصدر
`data/patterns.json` يحتوي 1,034 مدخلًا. كل `sourceIds` في المجموعة تشير إلى معرفات صحيحة لمدخلات ذات قرابة تعليمية، **ولا تعني أن جميع الأمثلة أو القوالب المضافة مقتبسة حرفيًا**؛ الفجوات سُدت بأمثلة أصلية.

## التفاعل والاختبارات
- استماع منفصل وتسلسلي، تشغيل بطيء، ترجمة، تظليل للكلمة وفق التوقيت الحقيقي عند وجود ملف مثبت.
- اختبار فهم واختبار ترتيب كلمات، ولا تحتسب المشاهد مكتملة إلا عند نجاح الاثنين.
- حفظ تقدم كل مجموعة في مساحة مستقلة؛ فحص واجهة الهاتف من دون تمرير أفقي.
- المراجعة السمعية البشرية النهائية مؤجلة حتى بعد إتمام التغطية الصوتية الآلية، والصور تُنتج في مرحلة مستقلة.

```sh
npm run check
node --check group-ten.js
python scripts/test_group_ten.py
python scripts/audit_ten_groups.py
# إعادة فحص جميع الأصول الصوتية الموثقة:
python scripts/test_group_ten.py --require-audio
python scripts/audit_ten_groups.py --require-ten-audio
node scripts/smoke_group_ten.mjs
```
