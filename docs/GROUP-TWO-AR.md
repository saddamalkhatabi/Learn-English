# المجموعة الثانية — الحياة اليومية والعادات

تأتي بعد مجموعة التعبير عن الذات والأشياء، وتحافظ على الأصول الصوتية ومزامنة كل كلمة قدر توفر بيانات WordBoundary المتحققة منها.

## المحتوى

- 18 نمطًا مرتبطًا بالروتين والعادات، وأربعة مشاهد واقعية اللغة لكل نمط: **72 موقفًا**.
- 54 سطر قصة قصيرة، و36 دورًا حواريًا، لكل منها ترجمة عربية.
- 3 قصص مترابطة: **My Morning** و**My School Day** و**My Weekend**؛ كل واحدة 6 جمل، أي 18 مقطعًا إضافيًا.
- شرح عربي وإنجليزي، مقارنة مع النمط القريب، وعرض تفاعلي واختبار فهم وترتيب كلمات.
- حفظ التقدم لكل مشهد محليًا، مع عدم التداخل مع تقدم المجموعة الأولى.
- بطاقات توضيحية مؤقتة تحل محل صور WebP إلى حين تصميم الأطالس لاحقًا؛ لا يوجد ملف صورة مزعوم.
- أنماط التركيز: **I wake up** و**I get up**، **In the morning**، **I brush my teeth**، **I have breakfast**، **I go to**، **I usually / always / often / sometimes / never**، **I eat**، **Before I / After I**، **Every day**، **At night**، **I go to bed**، **On weekends**.

## الصوت

- 198 مادة سردية مستهدفة: 18 شرحًا +72 موقفًا +54 قصة قصيرة +36 حوارًا +18 مقطعًا من القصص الثلاث.
- السكربت `scripts/render_group_two_audio.py` ينشئ تسجيلات Edge Neural TTS بصوت إنجليزي طبيعي ويستخرج **WordBoundary** من التسجيل ذاته.
- `data/group-two-audio-index.json` يبدأ فارغًا عمدًا إلى أن تُنتج التسجيلات وتتحقق وتُحفظ في Git. لا نؤكد اكتمال التسجيلات قبل نجاح الوظيفة.
- الصوت الطبيعي والبطيء وتلوين الكلمة بحسب توقيت MP3 متاح برمجيًا؛ نطق المتصفح بديل مؤقت حين لا تتوفر الملفات.

## الضوابط

- طبّق الفرق بين **wake up / get up** وبين **usually / always / often / sometimes / never** وبين **before / after**.
- المصدر الاصلي 1,034 مدخلًا محفوظ دون تعديل؛ `sourceIds` تشير إلى الأمثلة المرتبطة، ومنها المصدر رقم 19 و84 و120 و121 و125 و183. بقية المواقف توسع تعليمي مؤلف.
- راجع النطق بشريًا، وسرعة الانتقال ومزامنة الكلمات على الهاتف والتابلت.
- لا تنشر الصور الواقعية قبل وجود الملفات وإثبات مطابقتها للمشهد.

## التحقق

```bash
npm run check
node --check group-two.js
python scripts/test_group_two.py
```
