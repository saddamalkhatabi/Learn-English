# المجموعة الأولى — أساس التعبير عن الذات والأشياء

هذه المجموعة هي أول حزمة تعليمية من خطة المجموعات العشر، ومبنية على مستودع Learn-English القائم، لا بديلاً عنه.

## المحتوى الموجود
- 18 نمطًا مترابطًا، لكل واحد صيغة وشرح عربي وإنجليزي ومقارنة لغوية.
- 72 موقفًا تطبيقيًا (أربعة لكل نمط) مع ترجمة وسياق بصري؛ 54 سطر قصة و36 جملة حوارية.
- مشاهد قابلة للتنقل، ومقارنات وروابط بين الأنماط، واختبار اختيار العبارة ثم بناء الكلمات.
- حفظ التقدم محليًا. لا تكتمل التجربة إلا بنجاح اختبار المعنى وترتيب كلمات الجملة.
- استماع طبيعي وبطيء واستماع متتابع. تلوين الكلمات يتبع توقيتات MP3 الحقيقية فقط عند توفرها، أو حدود النطق التي يوفرها المتصفح.

## الوسائط — حدود الإنجاز الموثقة
- توجد ثلاث أطالس صور أصلية في مسارات this/have/got. تستخدم المجموعة 11 مشهدًا يطابق كل منها نص الصورة بالفعل.
- بقية 61 موقفًا تعرض تمثيلًا توضيحيًا معنونا **ولا تمتلك بعد صورة فوتوغرافية أصلية مستقلة**.
- يحتفظ المشروع بتسجيلات Kokoro السابقة، وبمكتبة نمط صوتي منفصلة. يعطي العرض الأولوية لتسجيلات Kokoro المطابقة للنص.
- فهرس أصوات المجموعة الجديدة يبدأ دون ملفات؛ المولد وملف GitHub Action لا يساويان الصوت المنشور.
- ينتج المولد الجديد تسجيلات Edge Neural TTS للشروح والمشاهد والقصص والحوارات، ويستخرج WordBoundary من نفس التسجيل، ثم يتحقق من البصمة وترتيب الكلمات وأزمنتها.
- يجب نجاح وظيفة group-one-voices.yml على main قبل اعتبار الأصوات الجديدة منجزة. وإلا يستخدم العرض نطق الجهاز دون ادعاء تزامن دقيق.

## المصادر والتوسع
تعتمد قائمة المجموعة على ملف الأنماط الذي يحفظ 1,034 مدخلاً من المصدر؛ لا نزيل التكرارات ولا نغير الأصل. تنويعات تعليمية مثل My name is وThat is ترتبط بمدخلات المصدر عبر sourceIds وليست مدخلات أصلية مستقلة.

## اختبار القبول
1. شغّل: npm run check ، node --check group-one.js ، python scripts/test_group_one.py.
2. افتح الموقع عبر HTTP واختبر وجود 18 بطاقة و72 موقفًا.
3. اختبر التنقل على الهاتف والتابلت بحيث يظهر الموقف وتجربته دون أن تختفي الأزرار.
4. استمع بالسرعة الطبيعية والبطيئة، واختبر الإيقاف والمزامنة للقصة والحوار. لا تلوين تخميني.
5. جرّب الإجابة الخاطئة والصحيحة وترتيب كلمات خاطئًا وصحيحًا؛ لا تُحسب التجربة مكتملة إلا بنجاح الاثنين.
6. حدث الصفحة وتحقق من التقدم، واختبر بقاء المكتبة والدروس الثلاثة كما هي.
7. تحقق من Actions وجودة الملفات السمعية والنطق بشريًا قبل اعتماد الصوت.

## المعلق قبل إعلان اكتمال الوسائط
إنتاج صور واقعية دقيقة لبقية 61 موقفًا، ثم نجاح نشر صوت المجموعة الجديدة واختباره سمعيًا، والتحقق من المعاينة العامة المنفصلة. مجرد الدمج في main لا يثبت نشر الموقع أو نجاح الأصوات.
